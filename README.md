# Een client-servervoorbeeld - Flutter / NestJS (2026)

Deze repository hoort bij de cursus **„Een client-servervoorbeeld - Flutter / NestJS (2026)”**, gepubliceerd op:

**https://stahe.github.io/nl-flutter-nestjs-sept-2026/**

## Overzicht

Dit document past de educatieve applicatie **RdvMedecins** (het plannen van afspraken bij de arts) – die al is behandeld in cursussen over Angular, React en Vue.js – aan op actuele technologieën. Hier wordt een mobiele versie gepresenteerd: een **Flutter**-client (Dart) die steunt op een **NestJS**-server (TypeScript) die een JSON-API aanbiedt, beveiligd met JWT-authenticatie (rollen ADMIN / USER).

Dit document is bedoeld voor lezers die al vertrouwd zijn met minstens één webframework (Angular, React of Vue.js) en Flutter leren door vergelijking: elk Flutter-concept wordt gekoppeld aan zijn equivalent in die frameworks.

De cursus behandelt:

- het inrichten van de ontwikkelomgeving (VSCode, Flutter-SDK, Android Studio, Android-SDK, het voorbereiden van een Android-telefoon en een emulator, `flutter doctor`);
- het installeren en uitvoeren van de NestJS-server van de app (MySQL-database, configuratie, testen met een browser en met Postman);
- een inleiding tot Flutter (widgets, `StatelessWidget`/`StatefulWidget`, toestandsbeheer met `provider`, de taal Dart);
- een gedetailleerd, bestand-voor-bestandoverzicht van de Flutter-client van de app RdvMedecins;
- het overzetten van dezelfde broncode naar drie doelfamilies: mobiel (Android/iOS), desktop (Windows/macOS/Linux) en web, waarbij de specifieke uitdagingen van mobiel aan bod komen (serveradres, onversleuteld HTTP-verkeer, smalle schermen);
- een conclusie over wat is gebouwd en mogelijkheden voor verdere ontwikkeling.
